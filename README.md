
# E-commerce Data Analytics

## Project Overview

This project explores an end-to-end data analytics workflow using a real-world e-commerce dataset. The goal is to transform raw data into meaningful business insights through data analysis, data modeling, and visualization.

The project will be developed incrementally, documenting the tools, methods, and findings at each stage.

## Business Objectives

- Analyze sales and order trends over time.
- Understand customer purchasing behavior.
- Evaluate product performance and delivery efficiency.
- Monitor key business metrics (KPIs).
- Explore forecasting techniques to identify potential future trends.

## Technology Stack

Tools will be introduced progressively as the project develops:

- **Git & GitHub:** Version control and project documentation.
- **Excel / Google Sheets:** Data exploration, spreadsheet analysis, and business reporting.
- **SQL:** Data querying, aggregation, and analysis.
- **Python:** Data cleaning, exploratory data analysis, and statistical analysis.
- **Power BI:** Interactive dashboards and business intelligence.
- **Machine Learning:** Exploratory forecasting and predictive analysis.
- **Cloud Technologies (Future Extension):** Potential use of cloud platforms for data storage, processing, and deployment.

## Dataset

The project will use the Brazilian E-Commerce Public Dataset by Olist, available on Kaggle.

Dataset source: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

The dataset contains information about orders, customers, products, payments, deliveries, and customer reviews.

Raw dataset files will not be uploaded directly to this repository.

## Project Status

**Status:** Initial setup

The project will be developed incrementally, starting with data exploration and spreadsheet analysis, followed by SQL, Python, data modeling, and visualization.

Forecasting, machine learning, and cloud technologies may be explored in later stages, depending on the progress and learning objectives.
